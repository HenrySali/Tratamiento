🚀 CÓMO USARLO DESDE TU COMPUTADORA:


PASO 1: Descargar el repositorio
────────────────────────────────
git clone https://github.com/HenrySali/Tratamiento.git
cd Tratamiento


PASO 2: Instalar dependencias (primera vez)
────────────────────────────────────────────
python -m venv venv
source venv/bin/activate       # (En Windows: venv\Scripts\activate)
pip install -r requirements.txt


PASO 3: Ejecutar el servidor
─────────────────────────────

EN LINUX/MAC:
$ ./run_web.sh

EN WINDOWS:
> run_web.bat

O MANUALMENTE:
$ source venv/bin/activate
$ python web_app.py


PASO 4: Abrir en navegador
──────────────────────────
Verás algo como:
  * Running on http://127.0.0.1:5000

Abre en tu navegador:
  ➜  http://localhost:5000


PASO 5: ¡Usar la interfaz!
──────────────────────────
1. Arrastra tu archivo de audio a la zona gris
   (O haz clic para seleccionar)

2. Selecciona el idioma
   (Español, Inglés, Francés, etc.)

3. Haz clic en "⚡ Procesar Audio"

4. Espera a que se complete
   (Verás los 5 pasos del proceso)

5. ¡Listo! Verás:
   ✓ Audio procesado (con reproductor)
   ✓ Transcripción completa
   ✓ Botones para descargar

✨ QUÉ PUEDES HACER:

📤 SUBIR AUDIOS:
  • Arrastra y suelta (drag & drop)
  • Haz clic para seleccionar
  • Soporta: WAV, MP3, OGG, FLAC, M4A
  • Máximo: 500MB

⚡ PROCESAR:
  • Reduce ruido automáticamente
  • Normaliza el volumen
  • Realza la presencia de voz
  • Transcribe con IA

🔊 ESCUCHAR:
  • Reproductor integrado
  • Controles: play, pause, volumen

📝 VER TRANSCRIPCIÓN:
  • Texto completo en pantalla
  • Copiar al portapapeles
  • Descargar como archivo

⬇️ DESCARGAR:
  • Audio procesado (WAV)
  • Transcripción (TXT)

🔧 TROUBLESHOOTING:

PROBLEMA: "Puerto 5000 en uso"
SOLUCIÓN: Edita web_app.py, última línea
          Cambia: port=5000 → port=8000

PROBLEMA: "Module not found"
SOLUCIÓN: pip install -r requirements.txt

PROBLEMA: "Slow processing"
SOLUCIÓN: Es normal. Whisper toma tiempo.
          Primera ejecución: ~2-3 minutos
          Siguientes: ~30-60 segundos por minuto de audio
